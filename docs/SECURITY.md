# Безопасность

- пароли хранятся в виде хешей Werkzeug;
- формы защищены CSRF-токенами;
- права проверяются на серверной стороне;
- загрузки ограничены расширением и размером;
- административные действия записываются в журнал;
- пользовательский Python-код проверяется через AST и запускается отдельным процессом с ограничениями.

Локальный исполнитель кода является демонстрационным. В публичной системе его необходимо вынести в отдельный контейнер без доступа к сети и файловой системе основного приложения.
