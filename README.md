# PythonStudy

Интерактивное образовательное веб-приложение по программированию на языке Python, разработанное на Flask.

## Возможности

- три роли: студент, преподаватель, администратор;
- регистрация, авторизация, восстановление и смена пароля;
- каталог курсов, модули, уроки и материалы;
- интерактивный редактор Python-кода и автоматическая проверка решений;
- тесты знаний, прогресс, достижения и уведомления;
- личный кабинет студента;
- кабинет преподавателя и самостоятельно разработанная панель администратора;
- форма обратной связи;
- экспорт отчетов в XLSX, DOCX и PDF;
- хлебные крошки, адаптивный интерфейс и более 10 самостоятельных страниц;
- SQLite для локального запуска и развертывания на PythonAnywhere.

## Быстрый запуск

Требуется Python 3.12.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
flask --app run.py db upgrade
flask --app run.py seed-demo
flask --app run.py run
```

Откройте `http://127.0.0.1:5000`.

Готовая демонстрационная SQLite-база находится в `data/pythonstudy.db`.

## Демонстрационные учетные записи

После команды `seed-demo`:

- администратор: `admin` / `admin`;
- преподаватель: `teacher` / `teacher`;
- студент: `student` / `student`.

Пароли следует заменить перед публикацией.

Демонстрационный курс содержит 8 модулей, 24 урока, 25 программных заданий, 75 тестовых случаев и 8 тестов знаний с 40 вопросами.

## PythonAnywhere

Проект поддерживает классическое WSGI-развертывание на PythonAnywhere с Python 3.12 и SQLite. Используйте [пошаговую инструкцию](docs/PYTHONANYWHERE.md).

## PostgreSQL

Укажите переменную:

```bash
DATABASE_URL=postgresql+psycopg://user:password@host:5432/database
```

## Запуск тестов

```bash

```

```bash

```

## Безопасность выполнения пользовательского кода

В проект включен ограниченный учебный исполнитель: AST-проверка, запрет опасных импортов и вызовов, отдельный процесс, тайм-аут, лимит вывода и ресурсные ограничения в Unix-системах. Это подходит для демонстрационной ВКР и локальной проверки. Для публичного сервиса с недоверенным кодом исполнитель необходимо вынести в изолированный контейнер без сети и с отдельным непривилегированным пользователем.
